01

Calgary Traffic Risk Intelligence

2026

Built an end-to-end traffic analytics and machine learning project using more than 64,000 Calgary traffic incident records. The project combines temporal analysis, DBSCAN-based hotspot detection, nearest traffic-control matching, historical weather data, a custom intersection-level risk index, and an hourly incident-activity prediction model. The results are presented through an interactive Streamlit dashboard with maps, charts, risk insights, and model predictions.

Python · Pandas · NumPy · scikit-learn · Plotly · Streamlit · Jupyter · DBSCAN · BallTree · Git/GitHub
